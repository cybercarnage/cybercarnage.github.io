# Сайт-резюме «Киберпанк + CRT»

Статический сайт: HTML5 + CSS + JS, без сборки и зависимостей (шрифты — Google Fonts CDN).

## Файлы

- `index.html` — разметка. Текст привязан к ключам через атрибуты:
  - `data-i18n="ключ"` — обычный текст,
  - `data-i18n-html="ключ"` — текст с HTML-разметкой (`<b>`, `<br>` и т.п.).
- `style.css` — три темы оформления (переключаются атрибутом `html[data-theme]`):
  - `gta6` — закат Vice City (палитра из wallpapers): пальмы, ретро-солнце, тёплые неоны;
  - `vicecity` — неон 80-х Yellowtail/Raleway: розовый #ff71ce, циан #01cdfe на тёмном индиго;
  - `cyberpunk` — зелёный неон Cyberpunk 2077.
  Плюс CRT-оверлей (сканлайны, RGB-маска, виньетка, луч, мерцание).
- `script.js` — вся логика, переключение языков и тем и **весь текст обеих языковых версий** в словаре `I18N` (блоки `ru` и `en`).

## Как добавить/поправить контент

1. Откройте `script.js`, найдите словарь `I18N`.
2. Ключи в блоках `ru` и `en` одинаковые — правьте значения в обоих.
3. Если добавляете **новый** элемент в `index.html`, дайте ему `data-i18n="новый.ключ"`
   и добавьте этот ключ в оба блока словаря.
4. Загрузочный экран — ключи `boot.l1`–`boot.l5`, печатающаяся строка — `hero.role`.

## Локальный просмотр

```bash
python3 -m http.server 8137
# открыть http://127.0.0.1:8137
```

Переключатели в шапке: тема (пальма = GTA6 / череп = киберпунк) и язык RU/EN — выбор обоих сохраняется в localStorage.
